* Personal dotfiles

** Configs

Every top-level directory is a [[https://www.gnu.org/software/stow/][GNU Stow]] package that mirrors =~=, with =dot-= standing in for a leading dot:

#+begin_example
  niri/dot-config/niri/config.kdl  ->  ~/.config/niri/config.kdl
  emacs/dot-emacs.d/init.el        ->  ~/.emacs.d/init.el
#+end_example

Deploy everything at once:

#+begin_src shell
  cd ~/dotfiles
  make check      # dry run
  make deploy     # symlink all packages into ~
  make undeploy   # remove those symlinks
  make redeploy   # unstow then stow, to prune stale links
  make list       # show which packages were detected
#+end_src

The package list is derived from the directory listing.

- =Makefile= uses =--dotfiles= by default.
- Directories in =EXCLUDE= in the =Makefile= are skipped.

** Portages
