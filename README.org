* Dotfiles

This repo contains /literate/ configurations for my devices.

The config are split into sections so they are more readable and easier to navigate. Once ready, they can be compiled (tangled) into target config files and read by the applications.

** Note

- Double-check target path before running. It overwrites.
- Property lines are read when the file opens. After editing =#+PROPERTY= line, refresh the file before tangling.
- The language name is the routing key. A block tagged =sh= or =shell= will not match =header-args:bash= and will fail silently.
- To disable a section, set =:tangle no= on the source block.
