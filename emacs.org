* About

** How this file works

Every =emacs-lisp= block below is written, top to bottom, into a single =init.el= by =C-c C-v t= (org-babel-tangle). The order of the headings is therefore the load order.

The tangle target is computed by the =#+PROPERTY= line at the top: a block goes to =init.el= unless its heading, or any parent heading, carries the =:INACTIVE:= tag. A single block can still opt out with =:tangle no=.

** Tags

- =:BINDING:=  The section defines some key binding.
- =:HOOK:=     The section installs some hook.
- =:ADVICE:=   The section installs some advice.
- =:FACE:=     The section modifies some face.
- =:MODE:=     The section activates a global mode.
- =:DEFER:=    Part of the section only runs once a package is loaded.
- =:PERSONAL:= The content might need adapting per machine (paths, fonts).
- =:OTHER:=    The section is tangled to a different file than =init.el=.
- =:INACTIVE:= The section is not tangled.

** Borders, mode line, and status line :FACE:HOOK:

Borders, dividers and fringes melt into the background. The mode line is collapsed to a thin rule and the status moves up into the header line. The colours are read from the current theme, so the function runs again whenever a theme is enabled.

#+begin_src emacs-lisp
(defun my/apply-chrome (&rest _)
  (let ((bg     (face-background 'default))
        (subtle (face-background 'mode-line-inactive nil t))
        (rule   (face-foreground 'shadow nil t)))
    (dolist (f '(internal-border window-divider fringe
                 window-divider-first-pixel window-divider-last-pixel))
      (set-face-attribute f nil :background bg :foreground bg))
    ;; Mode line collapsed to a thin rule
    (dolist (f '(mode-line mode-line-inactive))
      (set-face-attribute f nil :height 0.1 :box nil :overline nil
                          :foreground bg :background bg :underline rule))
    ;; Status bar lives in the header line instead
    (set-face-attribute 'header-line nil :background subtle :box nil
                        :underline nil :inherit nil)))

(my/apply-chrome)
(add-hook 'enable-theme-functions #'my/apply-chrome)
#+end_src

The header line shows the buffer name, the major mode, and the position at the right edge.

#+begin_src emacs-lisp
(setq x-underline-at-descent-line t)

Define explicitly which faces should be fixed-pitch as needed.

#+begin_src emacs-lisp
(defun my/fixed-pitch-faces (&rest faces)
  "Make FACES inherit `fixed-pitch', keeping their existing inheritance."
  (dolist (face faces)
    (let ((old (face-attribute face :inherit nil)))
      (set-face-attribute
       face nil :inherit
       (cons 'fixed-pitch
             (remq 'fixed-pitch
                   (if (eq old 'unspecified) nil (ensure-list old))))))))

(with-eval-after-load 'org
  (my/fixed-pitch-faces
   'org-table 'org-formula 'org-code 'org-verbatim 'org-block
   'org-meta-line 'org-special-keyword 'org-property-value 'org-drawer
   'org-document-info-keyword 'org-date))

(with-eval-after-load 'markdown-mode
  (my/fixed-pitch-faces
   'markdown-code-face 'markdown-pre-face 'markdown-inline-code-face
   'markdown-table-face 'markdown-language-keyword-face
   'markdown-language-info-face))

(with-eval-after-load 'org-modern
  (my/fixed-pitch-faces 'org-modern-label))

             '("\\.\\(?:md\\|markdown\\|mkd\\|mdown\\|mkdn\\|mdwn\\)\\'" . markdown-mode))

   "Major mode for editing GitHub Flavored Markdown files" t)

(with-eval-after-load 'markdown-mode

* PDF

** PDF viewing :HOOK:DEFER:

Any file starting with =%PDF= opens in =pdf-view-mode=, as one continuous scroll instead of page by page.

#+begin_src emacs-lisp
(autoload 'pdf-view-mode "pdf-view" nil t)
(add-to-list 'magic-mode-alist '("%PDF" . pdf-view-mode))

(setq pdf-view-continuous t)
(add-hook 'pdf-view-mode-hook #'pdf-view-roll-minor-mode)

(with-eval-after-load 'pdf-tools
  (pdf-loader-install))
#+end_src

SyncTeX backward search (click in the PDF, jump to the source). =pdf-sync-backward-search= hands this to =pop-to-buffer= as its action, and left unset it just splits the PDF's own frame. =reuse-window= with =reusable-frames= hands the jump to whatever frame already shows that source buffer; =pop-up-frame= only kicks in when no frame does.

#+begin_src emacs-lisp
(setq pdf-sync-backward-display-action
      '((display-buffer-reuse-window display-buffer-pop-up-frame)
        (reusable-frames . visible)
        (inhibit-same-window . t)))
#+end_src

** PDF in its own frame

Show the compiled PDF in a separate frame, instead of taking over the source window. =reuse-window= with =reusable-frames= picks up the frame from the previous compile, so re-running =C-c C-c= does not pile up frames.

#+begin_src emacs-lisp
(add-to-list 'display-buffer-alist
             '((derived-mode . pdf-view-mode)
               (display-buffer-reuse-window display-buffer-pop-up-frame)
               (reusable-frames . visible)
               (inhibit-same-window . t)
               (inhibit-switch-frame . t)
               (dedicated . t)))
#+end_src

** Remote :DEFER:PERSONAL:

TRAMP builds its own PATH from the list in =tramp-remote-path=. The earlier entries are checked first. The list can contain literal string paths and special variables, for example:

- =tramp-default-remote-path= : output of =getconf PATH= in remote.
- =tramp-own-remote-path= : output of =echo $PATH= in a remote login shell.

#+begin_src emacs-lisp
(with-eval-after-load 'tramp
  (dolist (d '("/usr/lib/llvm/21/bin"
               "/usr/lib/llvm/22/bin"
               tramp-own-remote-path))
    (add-to-list 'tramp-remote-path d)))
#+end_src

Ensure remote ~dir-locals.el~ loads.

#+begin_src emacs-lisp

** Agent :BINDING:

Copy a formatted prompt for the region or a defun.

#+begin_src emacs-lisp
(defun my/copy-prompt-stub (beg end)
  "Format an agent prompt stub for the region or the defun at point."
  (interactive
   (if (use-region-p)
       (list (region-beginning) (region-end))
     (let ((b (bounds-of-thing-at-point 'defun)))
       (unless b (user-error "No region or defun at point"))
       (list (car b) (cdr b)))))
  (let* ((root (if-let ((p (project-current))) (project-root p) default-directory))
         (file (file-relative-name (or buffer-file-name (user-error "Buffer has no file")) root))
         (l1 (line-number-at-pos beg))
         (l2 (line-number-at-pos (if (and (> end beg) (= (char-before end) ?\n)) (1- end) end)))
         (lang (replace-regexp-in-string "\\(-ts\\)?-mode\\'" "" (symbol-name major-mode)))
         (text (format "@%s#L%d-%d\n```%s\n%s\n```\n"
                       file l1 l2 lang
                       (string-trim-right (buffer-substring-no-properties beg end)))))
    (kill-new text)
    (deactivate-mark)
    (message "Copied %s:%d-%d as prompt stub" file l1 l2)))

(keymap-global-set "C-c C-a" #'my/copy-prompt-stub)
#+end_src
