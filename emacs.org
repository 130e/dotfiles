* About

** How this file works

Every =emacs-lisp= block below is written, top to bottom, into a single =init.el= by =C-c C-v t= (org-babel-tangle). The order of the headings is therefore the load order.

The tangle target is computed by the =#+PROPERTY= line at the top: a block goes to =init.el= unless its heading, or any parent heading, carries the =:INACTIVE:= tag. A single block can still opt out with =:tangle no=.

** Conventions

There is no =use-package=. The outline does the organising, so one heading holds everything about one topic, and the code under it is plain Emacs Lisp:

| use-package keyword | Written here as                                       |
|---------------------+-------------------------------------------------------|
| :ensure             | Nothing. Packages come from the system, see [[Packages]]  |
| :demand             | (require 'feature)                                    |
| :commands           | (autoload 'command "library" nil t)                   |
| :bind               | (keymap-global-set "KEY" #'command)                   |
| :hook               | (add-hook 'some-mode-hook #'function)                 |
| :mode, :magic       | (add-to-list 'auto-mode-alist ...) and friends        |
| :custom, :init      | (setq ...) at top level                               |
| :config, :after     | (with-eval-after-load 'feature ...), only when needed |

Two things =use-package= did silently now have to be spelled out:

- Autoloads :: =:bind=, =:hook= and =:mode= generated an autoload for the command they named. Most packages ship their own, but a few commands are missing from the system autoloads and get an explicit =autoload= line.
- Deferral :: A =setq= on a variable of a package that is not loaded yet is fine, the package keeps the value. Only code that calls into the package, or touches its faces, hooks and keymaps, needs =with-eval-after-load=.

** Tags

- =:BINDING:=  The section defines some key binding
- =:HOOK:=     The section installs some hook
- =:ADVICE:=   The section installs some advice
- =:FACE:=     The section modifies some face
- =:MODE:=     The section activates a global mode
- =:DEFER:=    Part of the section only runs once a package is loaded
- =:PERSONAL:= The content is personal (paths, fonts) and should be adapted
- =:OTHER:=    The section is tangled to a different file than =init.el=
- =:INACTIVE:= The section is not tangled

** Borders and status line :FACE:HOOK:

Borders, dividers and fringes melt into the background. The mode line is collapsed to a thin rule and the status moves up into the header line. The colours are read from the current theme, so the function runs again whenever a theme is enabled.

#+begin_src emacs-lisp
(defun my/apply-chrome (&rest _)
  (let ((bg     (face-background 'default))
        (subtle (face-background 'mode-line-inactive nil t))
        (rule   (face-foreground 'shadow nil t)))
    (dolist (f '(internal-border window-divider fringe
                 window-divider-first-pixel window-divider-last-pixel))
      (set-face-attribute f nil :background bg :foreground bg))
    ;; Mode line collapsed to a thin rule
    (dolist (f '(mode-line mode-line-inactive))
      (set-face-attribute f nil :height 0.1 :box nil :overline nil
                          :foreground bg :background bg :underline rule))
    ;; Status bar lives in the header line instead
    (set-face-attribute 'header-line nil :background subtle :box nil
                        :underline nil :inherit nil)))

(my/apply-chrome)
(add-hook 'enable-theme-functions #'my/apply-chrome)
#+end_src

The header line shows the buffer name, the major mode, and the position at the right edge.

** Mixed pitch :FACE:HOOK:DEFER:

Prose buffers use the proportional font. Everything that has to line up (tables, code, drawers, dates) is pinned back to the fixed-pitch one.

#+begin_src emacs-lisp
(defun my/fixed-pitch-faces (&rest faces)
  "Make FACES inherit `fixed-pitch', keeping their existing inheritance."
  (dolist (face faces)
    (let ((old (face-attribute face :inherit nil)))
      (set-face-attribute
       face nil :inherit
       (cons 'fixed-pitch
             (remq 'fixed-pitch
                   (if (eq old 'unspecified) nil (ensure-list old))))))))

(add-hook 'org-mode-hook      #'variable-pitch-mode)
(add-hook 'markdown-mode-hook #'variable-pitch-mode)

(with-eval-after-load 'org
  (my/fixed-pitch-faces
   'org-table 'org-formula 'org-code 'org-verbatim 'org-block
   'org-meta-line 'org-special-keyword 'org-property-value 'org-drawer
   'org-document-info-keyword 'org-checkbox 'org-date))

(with-eval-after-load 'markdown-mode
  (my/fixed-pitch-faces
   'markdown-code-face 'markdown-pre-face 'markdown-inline-code-face
   'markdown-table-face 'markdown-language-keyword-face
   'markdown-language-info-face))

(with-eval-after-load 'org-indent
  (my/fixed-pitch-faces 'org-indent))

(with-eval-after-load 'org-modern
  (my/fixed-pitch-faces 'org-modern-label 'org-modern-symbol))
#+end_src
