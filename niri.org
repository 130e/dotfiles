#+TITLE: Niri literate configuration
#+STARTUP: overview

* About

[[https://niri-wm.github.io/niri/][Niri]] is a scrollable-tiling Wayland compositor: windows sit in columns on an endless horizontal strip, and each monitor has its own vertical stack of workspaces. Its configuration is one [[https://kdl.dev][KDL]] file, =~/.config/niri/config.kdl=.

** How this file works

Niri refuses a config where a section such as =binds= or =layout= appears twice, so the blocks below cannot simply be written out one after the other. Instead:

- No block is tangled on its own. Each top-level heading gives its blocks a name through the =:noweb-ref= property in its drawer.
- The single block under [[Assembly]] is the only one with a =:tangle= target. It lays out the file and pulls the named pieces in with =<<name>>=.

So =C-c C-v t= still writes the whole file, and a new block under an existing heading is picked up automatically. A new top-level heading needs its own =:noweb-ref= and a line in [[Assembly]].

To disable a single node, put KDL's own =/-= in front of it. After tangling, check the result with =niri validate=; niri reloads the file by itself.

** Related files

- [[file:noctalia.org][noctalia.org]] :: The desktop shell (bar, launcher, notifications). Most of the program keys below talk to it.
- [[file:alacritty.org][alacritty.org]] :: The terminal opened by =Mod+Return=.
- [[file:emacs.org][emacs.org]] :: Emacs runs as a daemon started from here, and the capture frame it opens is floated by a window rule here.

** Keyboard

The modifiers are rearranged for Emacs: left Alt acts as Ctrl, left Ctrl as Super, left Super as Alt, and Caps Lock is one more Super. See xkeyboard-config(7) for the option names. Numlock is on at startup.

#+begin_src kdl
keyboard {
    xkb {
        options "ctrl:swap_lalt_lctl_lwin,caps:super"
    }

    numlock
}
#+end_src

** Touchpad

Tap to click, and natural (content follows fingers) scrolling. Mouse and trackpoint stay at their defaults.

#+begin_src kdl
touchpad {
    tap
    natural-scroll
}
#+end_src

** Gaps and centering

16 pixels between windows. Focusing a column never recenters the view, except that a lone column is always centered.

#+begin_src kdl
gaps 16

center-focused-column "never"
always-center-single-column
#+end_src

** Column widths

New windows take half the screen. =Mod+R= cycles through thirds and halves.

#+begin_src kdl
preset-column-widths {
    proportion 0.33333
    proportion 0.5
    proportion 0.66667
}

default-column-width { proportion 0.5; }
#+end_src

** Focus ring and border

A thin ring around the focused window only. The border (same thing, but drawn around every window) is off; its settings are kept for when it is switched back on.

The colours here are fallbacks: =noctalia.kdl=, included at the very end, overrides them to match the shell theme.

#+begin_src kdl
focus-ring {
    width 2
    active-color "#7fc8ff"
    inactive-color "#505050"
}

border {
    off

    width 4
    active-color "#ffc87f"
    inactive-color "#505050"
    urgent-color "#9b0000"
}
#+end_src

** Shadow

Off (there is no =on=), the values are the defaults kept at hand. They follow the CSS =box-shadow= properties.

#+begin_src kdl
shadow {
    softness 30
    spread 5
    offset x=0 y=5
    color "#0007"
}
#+end_src

* Window rules

** Workarounds

WezTerm's initial configure bug: let it pick its own width.

#+begin_src kdl
window-rule {
    match app-id=r#"^org\.wezfurlong\.wezterm$"#
    default-column-width {}
}
#+end_src

** Floating windows

Small or transient windows that make no sense as a full-height column.

*** Firefox

Picture-in-picture player.

#+begin_src kdl
window-rule {
    match app-id=r#"firefox-esr"# title="^Picture-in-Picture$"
    open-floating true
}
#+end_src

Firefox notifications have an empty title. They show up in the top-right corner and do not steal focus.

#+begin_src kdl
window-rule {
    match app-id="^firefox" title="^$"
    open-focused false
    open-floating true
    default-floating-position x=10 y=10 relative-to="top-right"
}
#+end_src

*** Emacs

The Emacs frame opened for a capture, by =Mod+Shift+C= below or by the =org-protocol= handler. Both name the frame =emacs-temp-frame=, and Emacs deletes it when the capture is done, see [[file:emacs.org::*Capture from the browser][Capture from the browser]].

#+begin_src kdl
window-rule {
    // match app-id="^emacs(?:-[0-9]+)?$" title=r#"^CAPTURE-(?:.+)\.org$"#
    match app-id="^emacs(?:-[0-9]+)?$" title="^emacs-temp-frame$"
    open-floating true
}
#+end_src

* Key bindings
:PROPERTIES:
:header-args:kdl: :noweb-ref binds :noweb-sep "\n\n"
:END:

=Mod= is Super in a real session (and Alt when niri runs nested in a window). Key names are XKB names, =wev= shows the name of any key. Every action here can also be run as =niri msg action ...=.

Keep the modifier swap from [[Keyboard]] in mind: the physical key that sends Super is left Ctrl, or Caps Lock.

** Help

=Mod+?= lists the important hotkeys.

#+begin_src kdl
Mod+Shift+Slash { show-hotkey-overlay; }
#+end_src

** Mouse wheel

With =Mod= held, the wheel scrolls through workspaces. The cooldown keeps a fast wheel from flying through all of them.

#+begin_src kdl
Mod+WheelScrollDown      cooldown-ms=150 { focus-workspace-down; }
Mod+WheelScrollUp        cooldown-ms=150 { focus-workspace-up; }
Mod+Ctrl+WheelScrollDown cooldown-ms=150 { move-column-to-workspace-down; }
Mod+Ctrl+WheelScrollUp   cooldown-ms=150 { move-column-to-workspace-up; }
#+end_src

Sideways it scrolls through columns. =Shift= turns the vertical wheel into a horizontal one, as it does inside applications.

#+begin_src kdl
Mod+WheelScrollRight      { focus-column-right; }
Mod+WheelScrollLeft       { focus-column-left; }
Mod+Ctrl+WheelScrollRight { move-column-right; }
Mod+Ctrl+WheelScrollLeft  { move-column-left; }

Mod+Shift+WheelScrollDown      { focus-column-right; }
Mod+Shift+WheelScrollUp        { focus-column-left; }
Mod+Ctrl+Shift+WheelScrollDown { move-column-right; }
Mod+Ctrl+Shift+WheelScrollUp   { move-column-left; }
#+end_src

** Columns

Brackets move the focused window in and out of a column: a lone window is consumed into the neighbouring column, a window already in a column is expelled.

#+begin_src kdl
Mod+BracketLeft  { consume-or-expel-window-left; }
Mod+BracketRight { consume-or-expel-window-right; }
#+end_src

Comma takes the window to the right into the bottom of the focused column, period pushes the bottom window back out.

#+begin_src kdl
Mod+Comma  { consume-window-into-column; }
Mod+Period { expel-window-from-column; }
#+end_src

Show the windows of a column as tabs instead of stacking them.

#+begin_src kdl
Mod+W { toggle-column-tabbed-display; }
#+end_src

** Sizes

Cycle through the presets from [[Column widths]], forwards and backwards, and the same for heights.

#+begin_src kdl
Mod+R { switch-preset-column-width; }
Mod+Shift+R { switch-preset-column-width-back; }

Mod+Ctrl+Shift+R { switch-preset-window-height; }

#+end_src

Three ways to make a window big: =F= keeps the gaps, =M= goes to the screen edges like a normal maximize, =Shift+F= is real fullscreen. =Ctrl+F= fills whatever space the other visible columns leave.

#+begin_src kdl
Mod+F { maximize-column; }
Mod+Shift+F { fullscreen-window; }
Mod+M { maximize-window-to-edges; }
Mod+Ctrl+F { expand-column-to-available-width; }
#+end_src

Center the focused column, or all visible ones.

#+begin_src kdl
Mod+C { center-column; }
Mod+Ctrl+C { center-visible-columns; }
#+end_src

** Session

Remote-desktop clients and software KVM switches may ask niri to stop handling its own shortcuts. This is the escape hatch, and it cannot be inhibited itself.

#+begin_src kdl
Mod+Escape allow-inhibiting=false { toggle-keyboard-shortcuts-inhibit; }
#+end_src

Power off the monitors, any input wakes them up again. Quitting niri goes through the Noctalia session menu (=Mod+Shift+E=), so the built-in =quit= action is not bound.

#+begin_src kdl
Mod+Shift+P { power-off-monitors; }
#+end_src

* Assembly

The only tangled block. It decides the order of the sections in =config.kdl= and wraps the pieces that niri wants inside a single node.

The last line pulls in =~/.config/niri/noctalia.kdl=, which Noctalia regenerates whenever its theme changes (see [[file:noctalia.org::*Theme][Theme]]). It comes last so that its colours win over the ones in [[Focus ring and border]]. That file is not managed here.

#+begin_src kdl :tangle ~/.config/niri/config.kdl :mkdirp yes :noweb yes
// config.kdl --- generated from niri.org, do not edit

input {
    <<input>>
}

<<outputs>>

layout {
    <<layout>>
}

<<startup>>

<<misc>>

<<window-rules>>

binds {
    <<binds>>
}

include "noctalia.kdl"
#+end_src
