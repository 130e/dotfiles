#+TITLE: Niri literate configuration
#+STARTUP: overview

* About

[[https://niri-wm.github.io/niri/][Niri]] is a scrollable-tiling Wayland compositor. This file writes to =~/.config/niri/config.kdl=. This is the only tangled block. It decides the order of the sections in =config.kdl= and wraps the pieces inside a single node.

Note: The last line pulls in =~/.config/niri/noctalia.kdl=, which Noctalia regenerates whenever its theme changes (see [[file:noctalia.org::*Theme][Noctalia.org:Theme]]).

#+begin_src kdl :tangle ~/.config/niri/config.kdl :mkdirp yes :noweb yes
// config.kdl --- generated from niri.org, do not edit

input {
    <<input>>
}

<<outputs>>

layout {
    <<layout>>
}

<<startup>>

<<misc>>

<<window-rules>>

binds {
    <<binds>>
}

include "noctalia.kdl"
#+end_src

** Keyboard

The modifiers are rearranged for Emacs: left Alt acts as Ctrl, left Ctrl as Super, left Super as Alt, and Caps Lock is one more Super. See =xkeyboard-config(7)= for the option names.

#+begin_src kdl
keyboard {
    xkb {
        options "ctrl:swap_lalt_lctl_lwin,caps:super"
    }
}
#+end_src

** Touchpad

Tap to click, and natural scrolling.

#+begin_src kdl
touchpad {

    natural-scroll
}

** Workarounds

WezTerm's initial configure bug: let it pick its own width.

#+begin_src kdl
window-rule {
    match app-id=r#"^org\.wezfurlong\.wezterm$"#
    default-column-width {}
}
#+end_src

** Floating windows

Small or transient windows that make no sense as a full-height column.

*** Firefox

Picture-in-picture player.

#+begin_src kdl
window-rule {
    match app-id=r#"firefox-esr"# title="^Picture-in-Picture$"
    open-floating true
}
#+end_src

Firefox notifications have an empty title. They show up in the top-right corner and do not steal focus.

#+begin_src kdl
window-rule {
    match app-id="^firefox" title="^$"
    open-focused false
    open-floating true
    default-floating-position x=10 y=10 relative-to="top-right"
}
#+end_src

*** Emacs

Work in tandem with [[file:emacs.org][Emacs dotfile]]. Temporary Emacs frames (e.g., for org-capture and calendar) should be floating.

#+begin_src kdl
window-rule {
    // match app-id="^emacs(?:-[0-9]+)?$" title=r#"^CAPTURE-(?:.+)\.org$"#
    match app-id="^emacs(?:-[0-9]+)?$" title="^emacs-temp-frame$"
    open-floating true
    default-column-width { fixed 830; }
    default-window-height { fixed 700; }
}
#+end_src

** Mouse wheel

With =Mod= held, the wheel scrolls through workspaces. The cooldown keeps a fast wheel from flying through all of them.

#+begin_src kdl
Mod+WheelScrollDown      cooldown-ms=150 { focus-workspace-down; }
Mod+WheelScrollUp        cooldown-ms=150 { focus-workspace-up; }
Mod+Ctrl+WheelScrollDown cooldown-ms=150 { move-column-to-workspace-down; }
Mod+Ctrl+WheelScrollUp   cooldown-ms=150 { move-column-to-workspace-up; }
#+end_src

Sideways it scrolls through columns. =Shift= turns the vertical wheel into a horizontal one, as it does inside applications.

#+begin_src kdl
Mod+WheelScrollRight      { focus-column-right; }
Mod+WheelScrollLeft       { focus-column-left; }
Mod+Ctrl+WheelScrollRight { move-column-right; }
Mod+Ctrl+WheelScrollLeft  { move-column-left; }

Mod+Shift+WheelScrollDown      { focus-column-right; }
Mod+Shift+WheelScrollUp        { focus-column-left; }
Mod+Ctrl+Shift+WheelScrollDown { move-column-right; }
Mod+Ctrl+Shift+WheelScrollUp   { move-column-left; }
#+end_src

** Columns

Brackets move the focused window in and out of a column: a lone window is consumed into the neighbouring column, a window already in a column is expelled.

#+begin_src kdl
Mod+BracketLeft  { consume-or-expel-window-left; }
Mod+BracketRight { consume-or-expel-window-right; }
#+end_src

Comma takes the window to the right into the bottom of the focused column, period pushes the bottom window back out.

#+begin_src kdl
Mod+Comma  { consume-window-into-column; }
Mod+Period { expel-window-from-column; }
#+end_src

Show the windows of a column as tabs instead of stacking them.

#+begin_src kdl
Mod+T { toggle-column-tabbed-display; }
#+end_src

** Sizes

Cycle through the presets from [[Column widths]].

#+begin_src kdl
Mod+R { switch-preset-column-width; }
Mod+Shift+R { switch-preset-column-width-back; }

Mod+Ctrl+Shift+R { switch-preset-window-height; }
Mod+Ctrl+R { reset-window-height; }
#+end_src

Three ways to make a window full size:

1. Full width but keeps the gaps.
2. To the screen edges like a normal maximize.
3. Real fullscreen.
4. Fills only remaining space the other visible columns leave.

#+begin_src kdl
Mod+W { maximize-column; }
Mod+Shift+W { fullscreen-window; }
Mod+M { maximize-window-to-edges; }
Mod+Ctrl+W { expand-column-to-available-width; }
#+end_src

Center the focused column, or all visible ones.

#+begin_src kdl
Mod+C { center-column; }
Mod+Ctrl+C { center-visible-columns; }
#+end_src

Finer steps. The argument can also be absolute (="1000"=, ="25%"=) or in pixels (="+5"=).

#+begin_src kdl
Mod+Minus { set-column-width "-10%"; }
Mod+Equal { set-column-width "+10%"; }

Mod+Shift+Minus { set-window-height "-10%"; }
Mod+Shift+Equal { set-window-height "+10%"; }
#+end_src
