* About

Noctalia is the desktop shell on top of niri: bar, launcher, GUI control interface, notifications, and lock-screen. It's launched from [[file:niri.org][niri.org]].

It has two layers of settings:

- =~/.config/noctalia/config.toml= :: Generated by this file. Put persistent configurations here.
- =~/.local/state/noctalia/settings.toml= :: Written by the settings app. This overrides above on conflicting keys.

Here is the header:

#+begin_src toml
# config.toml --- generated from noctalia.org, do not edit
# config_version = 1
#+end_src

* Font

A Sans font is usually better for UI.

#+begin_src toml
[shell]
font_family = "Iosevka Aile"
#+end_src

* Theme

Follow system light/dark mode, automatically triggered by [[*Location and weather][weather]].

Note that Noctalia seems to regenerate the application theme templates when changing those from GUI, including  =~/.config/niri/noctalia.kdl= read by [[file:niri.org::*Assembly][niri]].

#+begin_src toml
[theme]
builtin = "Noctalia"
mode = "auto"

    [theme.templates]
    builtin_ids = [ "gtk3", "gtk4", "niri"]
#+end_src

* Bar

#+begin_src toml
[bar.default]
start = [ "launcher", "workspaces" ]
#+end_src

** Widgets

Icons only for brightness, network and volume. The media widget disappears when nothing is playing.

#+begin_src toml
[widget.brightness]
show_label = false

[widget.network]
show_label = false

[widget.volume]
mute_color = "secondary"
show_label = false

[widget.media]
hide_when_no_media = true
#+end_src

Date and 12-hour time. The format string is strftime-like.

#+begin_src toml
[widget.clock]
format = "📅 {:%a %b %d} 🕰 {:%I:%M %p}"
#+end_src

* Notifications and OSD

Keep a day of notification history. No on-screen display when the keyboard layout changes.

#+begin_src toml
[audio]
enable_sounds = true

[notification]
history_retention_hours = 24

[osd.kinds]
keyboard_layout = false
#+end_src

* Location and weather

Locate automatically, temperatures in Fahrenheit.

#+begin_src toml
[location]
auto_locate = true

[weather]
unit = "imperial"

[nightlight]
enabled = true
#+end_src
